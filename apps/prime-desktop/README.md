# Prime Hermes Desktop

Desktop harness for **Prime Agent** — Hermes' UX, Prime's engine.

A market-ready Electron app that ships its own gateway (double-click to run —
zero setup), surfaces Hermes' full capability set (skills hub, cron, MCP,
tools, profiles, webhooks, files, terminal, review), and makes Prime's unique
capabilities first-class surfaces (DAG plans, kernel, agents, graph, ledger,
self-improve).

## Build

```bash
npm ci
node scripts/bundle-runtime.mjs --src <repo-root>   # embeds gateway runtime
npm run build                                        # vite + electron bundle
npm run builder -- --win nsis                        # installer (NSIS)
```

## Release / auto-update

- Channel: GitHub Releases on this repo (`latest.yml` generated by the builder).
- Publish: `npm run builder -- --win nsis --publish always` (needs `GH_TOKEN`).
- Check for updates lives in Settings → Updates.

## Code signing (Windows)

The installer is signed with a local cert by default. For distribution past
SmartScreen / Device Guard:

1. Obtain a CA-trusted code-signing certificate (EV/OV) or use Azure Trusted
   Signing / SignPath.
2. Set `CSC_LINK` (path or base64 of the .pfx) and `CSC_KEY_PASSWORD`, then
   rebuild: `npm run builder -- --win nsis`.
3. Verify: `signtool verify /pa PrimeHermes-0.1.0-win-x64.exe`.

## Prime RPC (self-learning)

The Self-Improve pane drives the live Prime worker over the ariadne prime
bridge (`hermes_cli/web_routers/ariadne_prime.py`):

- `POST /api/ariadne/prime/start` — spawn `prime-agent --mode rpc`
- `POST /api/ariadne/prime/prompt {goal}` — run a refine goal
- `GET /api/ariadne/prime/state` — live kernel/session state
- `POST /api/ariadne/prime/steer {message}` — RLM-style steer
- `POST /api/ariadne/prime/stop`

Requires a model-provider env var (e.g. `ANTHROPIC_API_KEY`) for the bridge
process, and `PRIME_BRIDGE_SCRIPTS_DIR` pointing at the Hermes scripts dir
when it's not the default install location.
